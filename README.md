# TFCチーム記録ツール

THE FULL CREW のメンバーが、各自のランニング記録（距離・時間・ペース・心拍など）を
自分で入力し、先生（指導者）は全員の状況を横断的に見られる、チーム共有の記録ツール。

自分専用のマラソン記録サイト（`ランニング記録/` フォルダ）とは別物。あちらは1人用、
こちらはチーム全員が使う共有ツール。

## どこに何があるか

| | |
|---|---|
| `index.html` | アプリ本体。これをブラウザで開く（公開後はURLを開く） |
| `config.js` | Supabaseの接続情報を書き込むファイル（まだ未設定） |
| `schema.sql` | Supabase側に貼り付けて実行する、データの入れ物の定義 |
| `20260906_セットアップ手順.md` | Supabaseを設定する手順（初心者向けに詳しく） |
| `manifest.webmanifest` | スマホのホーム画面に追加したときアプリっぽく見せるための設定 |

## 仕組みのポイント（あとで思い出すためのメモ）

- **識別方法**：名前を選んでPIN（4〜6桁の数字）でログイン。本格的なアカウント登録ではなく、
  「うっかり他人のふりをしない」程度の軽い仕組み。ブラウザに記憶されるので毎回入力は不要
- **公開範囲**：本人と先生だけが見る想定で作っているが、Supabaseの仕組み上、
  データ自体はアクセスキーを知っていれば誰でも読み書きできる状態（=厳密な非公開ではない）。
  少人数の信頼できるチーム前提の割り切り
- **先生の見分け方**：最初にコーチとして登録した1人だけが「先生」ロールになる。
  一度先生が登録されると、以降の新規登録では先生チェックボックスは出ない
- **記録項目**：距離・時間・ペース・心拍は必須（すべて時計の表示をそのまま手入力）。
  ピッチ・接地時間・体感(RPE)・メモは任意
- **メンバー同士のランキング等**：意図的になし（本人＋先生のやり取りのみに絞る方針）

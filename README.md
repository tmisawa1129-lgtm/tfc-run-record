# TFCチーム記録ツール

THE FULL CREW のメンバーが、各自のランニング記録（距離・時間・ペース・心拍など）を
自分で入力し、先生（指導者）は全員の状況を横断的に見られる、チーム共有の記録ツール。

自分専用のマラソン記録サイト（`ランニング記録/` フォルダ）とは別物。あちらは1人用、
こちらはチーム全員が使う共有ツール。

## どこに何があるか

| | |
|---|---|
| `index.html` | アプリ本体。これをブラウザで開く（公開後はURLを開く） |
| `config.js` | Supabaseの接続情報（設定済み） |
| `schema.sql` | Supabase側で実行した、データの入れ物の定義 |
| `20260906_セットアップ手順.md` | Supabaseを設定した手順の記録（設定済みのため作業自体は不要） |
| `manifest.webmanifest` | スマホのホーム画面に追加したときアプリっぽく見せるための設定 |
| `sync_tetsu.py` | `ラン記録_マスター.csv` から Tetsu の記録をこのツールへ同期するスクリプト |

### Tetsuの記録を同期する

`ランニング記録/2_記録データ/ラン記録_マスター.csv` に新しい行を足したあと、
ターミナルで以下を実行すると、まだ登録されていない記録だけが追加される。

```
cd "/Users/mt/Documents/Claude Code/ランニング記録/TFCチーム記録ツール"
python3 sync_tetsu.py            # 追加する
python3 sync_tetsu.py --dry-run  # 追加せず内容だけ確認する
```

何度実行しても二重登録にはならない（日付＋距離が一致する記録はスキップする）。
心拍が空の行はツール側で心拍が必須のためスキップされる（2026-07-18の1件が該当）。

メモ欄について：CSVの「備考」は自分用の書き方（自己ベスト表記など）なので**同期しない**。
代わりに「Zone2 91%」のような客観的な数値だけを自動で入れる。
練習の中身（坂道・ロング走など）の振り返りを足したいときは、アプリの編集から手で書き足す
（2026-09-14に既存13件のメモを客観的な振り返りに書き直し済み）。

### Tetsuの記録を更新するときのルール（別の会話から更新する場合も同じ）

2026-09-15から、普段のラン記録を投げている別の会話でもこのツールへ反映している。
どこから更新する場合も以下を守る。

1. **追加は `python3 sync_tetsu.py` を使うのが基本**。直接Supabaseに書き込む場合も、
   同じ日付＋距離の記録がすでにないか先に確認する（二重登録防止）
2. **削除はできない設定になっている**（Supabase側で本当の削除を禁止）。
   間違えた記録は PATCH（更新）で直すか、`deleted_at` に日時を入れて隠す。
   「消して入れ直す」をすると、削除が黙って失敗して記録が2件になるので注意
3. **メモは客観的な内容だけ**（例：「平坦なコース。Zone2 91%、ピッチ174」）。
   マスターCSVの「備考」にある「過去最高」「自己ベスト」などの表現はチームに見えるので書かない
4. 心拍が空の記録は入れない（ツール側で心拍が必須）

2. `index.html` の `HOMEWORK.weeks` の末尾に1つ足す（`label` / `range` / `theme` / `img`）

毎週どちらも更新する。宿題の原本は `3_先生からの資料/宿題/日付_第○週宿題_テーマ/`。

## 仕組みのポイント（あとで思い出すためのメモ）

- **識別方法**：名前を選ぶだけ（PINなし）。当初PINもあったが、Supabase側がそもそも
  誰でも読み書きできる設定なので実質的なセキュリティ効果がないと判断し撤廃した。
  ブラウザに記憶されるので毎回選び直す必要はない
- **公開範囲**：当初は「本人＋先生のみ」の想定だったが、もともとLINEグループで
  日々の記録を共有する文化があり見られる抵抗感が薄いとわかったため、
  「みんなの状況」タブで全メンバーの走行状況（直近7日/30日の距離・最終記録日・
  直近RPE・メモ）を全員に公開する方針に変更した（2026-09-06）。
  なお技術的にはSupabase側は誰でも読み書きできる設定なので、そもそも厳密な
  非公開の保証はない。少人数の信頼できるチーム前提の割り切り
- **先生の見分け方**：DB上は「先生」ロールを持つ人が1人いる（バッジ表示用）。
  ただし機能的な区別はもう無く、先生専用のログインや画面はない
- **画面構成（2026-09-08に整理）**：タブは1段だけ。ログイン後は
  「記録を入力／記録一覧／みんなの状況／ガイド」の4つ、未ログイン時は
  「みんなの状況／ガイド」の2つ（ヘッダーに名前選択のログイン欄が出る）。
  以前は「ホーム」タブの中にさらにタブがある2段構造だったが、
  ややこしいので1段にフラット化した
- **ガイドタブの中身**：TFC ナレッジベース／参加者ガイド／勝田マラソン公式を
  小さいピルボタンで切り替えてiframe表示。その下に「別のタブで開く」リンク。
  以前あった「⚙ 大会設定」フォームは、誰でも触れてカウントダウンがずれる恐れがあるため
  2026-09-15に削除し、Supabase側でも大会設定を読むだけにした。
  変更が必要なときはSupabaseのSQL Editor（管理者）で race_config を直接更新する
- **モバイル最適化（2026-09-09）**：スマホ利用がメインのため、620px以下では
  レイアウトを切り替えている。①タブバーを画面下に固定（親指で届く位置）
  ②記録一覧の表を1件=1カードに積み直して横スクロールを解消
  ③入力欄を16pxにしてiOSの自動ズームを防止 ④ボタンのタップ領域を拡大
  ⑤ヘッダーを圧縮（THE FULL CREWを1行に、eyebrowを非表示）。
  PC幅では従来どおり上部タブ＋表形式で表示される
- **外部リンクの埋め込み**：ガイドタブの「TFC ナレッジベース」「参加者ガイド」
  「勝田マラソン公式」はiframeでその場に埋め込み表示（別タブで開くのではない）。
  3サイトともフレーム埋め込みを許可していることを事前に確認済み
- **記録項目**：距離・時間・ペース・心拍は必須（すべて時計の表示をそのまま手入力）。
  ピッチ・接地時間・体感(RPE)・メモは任意
- **入力の手間を減らす工夫**：ペースは距離と時間から自動計算（空欄のときだけ）。
  ピッチ・接地時間は前回値を初期値に引き継ぐ。「前回の記録をコピー」ボタンで
  同じような練習の日はワンクリックで全項目コピーできる
- **削除は「隠すだけ」（2026-09-14）**：削除ボタンは記録に `deleted_at`（削除日時）を入れて
  画面から隠すだけ。誤って消しても、Supabaseでその列を空に戻せば復活する。
  あわせてアプリのキーでは本当の削除（記録・メンバー・大会設定）をできない設定にした。
  他人の記録を編集・削除できてしまう点は、ログインなしの設計上の割り切り
- **入力ミスの確認（2026-09-14）**：距離50km超、心拍60未満/210超、未来の日付、
  距離×時間から計算したペースと入力ペースが15%以上違う、などのときは保存前に確認を出す
  （保存は止めない）
- **検索よけ**：`<meta name="robots" content="noindex">` で検索エンジンに載らないようにしている
- **バックアップ**：Supabase無料プランは自分でバックアップを取り出せないため、
  `python3 backup_records.py` で月1回程度、手元に保存する
